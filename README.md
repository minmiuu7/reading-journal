# 📚 책 — 읽은 책 · 읽는 책

**무료 개인용 독서 기록 웹앱**입니다.
`index.html` 파일 하나로 동작합니다. 빌드·서버·설치·회원가입 없이, 열면 바로 쓸 수 있고 데이터는 브라우저 안(localStorage)에만 저장됩니다.

## 여는 방법

- **Mac**: `index.html`을 더블클릭 (Safari/Chrome에서 열립니다)
- **iPhone**: 파일 앱이나 iCloud Drive에 올린 뒤 Safari로 열기 → 공유 → **홈 화면에 추가** 하면 앱처럼 쓸 수 있어요
- **인터넷 주소로 쓰기**: GitHub Pages에 올리면 폰·맥 어디서나 같은 주소로 열 수 있습니다 (아래 참고)

## 화면

- **서재**: 상단 요약(`N권 · 조각 M장`), 상태 탭(`전체 / 읽는 중 / 완독 / 중단`), 분야 칩, 표지 그리드(모바일 3열 / 데스크톱 5열), 표지 좌측 하단 `No. N` 배지
- **책 상세**(표지를 누르면 열림): 분야·상태 배지, 제목·저자·출판사·시작일·완독일·마지막 기록·조각 수, 상태 변경, `하이라이트 모아보기`, `읽는 이유` 카드, 마크다운 독서 노트
- **하단 탭바**: 홈 / 콘텐츠 / 책 / 생각지도 (지금은 `책`만 동작하고 나머지는 준비 중 안내가 뜹니다)

## 책 추가

`+ 책 추가` → 제목을 검색하면 표지·저자·출판사가 자동으로 채워집니다.

| 검색 소스 | 키 필요 | 비고 |
|---|---|---|
| Google Books | 없음 | 기본. 무료 한도가 찼을 때(429)는 자동으로 Open Library로 넘어갑니다 |
| Open Library | 없음 | openlibrary.org, 키 없이 무료 |
| 알라딘 | TTBKey | 알라딘 Open API에서 무료 발급. JSONP 방식이라 서버 없이 브라우저에서 바로 호출됩니다 |
| 카카오 | REST API 키 | developers.kakao.com → 내 애플리케이션 → REST API 키 |

키는 ⚙️ **설정 및 백업**에서 넣고, 이 브라우저에만 저장됩니다. 검색이 안 되거나 다른 표지를 쓰고 싶으면 **직접 입력**하고, 표지 이미지는 URL을 붙여넣거나 파일로 올리면 됩니다(자동으로 줄여서 저장).

**표지 붙여넣기**: 알라딘 같은 사이트에서 표지 이미지를 복사해 `책 추가`/`정보 수정` 창에서 `Cmd+V`(휴대폰은 입력칸을 길게 눌러 붙여넣기)만 하면 표지로 바로 들어갑니다. 이미지 파일이면 가로 480px으로 줄여 넣고, 이미지 주소(`https://...jpg`)를 붙여넣으면 URL 칸에 채워집니다.

## 독서 노트 (마크다운)

| 쓰는 법 | 결과 |
|---|---|
| `# 제목` `## 소제목` `### 소제목` | 제목 |
| `**굵게**` `*기울임*` `` `코드` `` `~~취소선~~` | 글자 꾸미기 |
| `> 인용` | 따뜻한 살구색 인용 박스 |
| `- 목록` / `1. 번호` | 목록 |
| `- [ ] 할 일` / `- [x] 한 일` | 체크리스트 (미리보기에서 눌러 바로 체크 가능) |
| `---` | 구분선 |

상단 툴바(`제목·굵게·기울임·인용구·목록·번호·체크·구분선`)로도 넣을 수 있고, **편집 / 미리보기 / 나란히**(데스크톱)로 봅니다. 입력하는 즉시 자동 저장됩니다.
책별 노트는 `↓ .md 내려받기`로 파일로 받을 수 있습니다.

## 폰트 설정 (⚙️ 설정 및 백업)

서재와 독서 노트의 글꼴을 바꿀 수 있습니다. 고른 폰트와 적용 범위는 이 브라우저에 저장되어 새로고침해도 유지됩니다.

| 선택지 | 글꼴 |
|---|---|
| 기본 고딕 | 지금의 시스템 산세리프 (Pretendard → Apple SD Gothic Neo) |
| 감성 명조 | Google Fonts **Noto Serif KR** (불러오지 못하면 시스템 명조) |
| 따뜻한 돋움 | Google Fonts **Gowun Dodum** |
| 손글씨 느낌 | Google Fonts **Nanum Pen Script** |
| 내 폰트 파일 | `.ttf` · `.otf` · `.woff` · `.woff2` 업로드 |

- **적용 범위**: `전체 화면`(제목·탭·버튼까지) 또는 `독서 노트만`(노트 편집·미리보기만).
- **내 폰트 파일**: 고른 파일은 `localStorage` 5MB 한도와 별개로 **IndexedDB**에 저장되고, 페이지를 열 때 `FontFace`로 자동 등록됩니다. `내 폰트 삭제 / 기본값으로`로 지울 수 있습니다. 다른 프리셋을 쓰다가 `저장된 내 폰트 적용`으로 다시 되돌릴 수 있습니다.
- 구글 폰트는 고른/미리볼 때만 그때그때 내려받습니다(오프라인이면 시스템 글꼴로 대체).
- 올린 폰트 파일은 JSON 백업에 들어가지 않습니다. 다른 기기에서 쓰려면 그 기기에서 다시 올려 주세요.

## 백업

⚙️ 설정 및 백업 →
- **JSON 내보내기**: 서재 전체(책·노트·상태·표지)를 파일 하나로 저장
- **JSON 가져오기**: 다른 기기에서 만든 JSON을 이 서재에 **합칩니다** (이미 있는 책은 건너뜀)

> 데이터는 이 브라우저에만 있습니다. 브라우저 데이터를 지우거나 시크릿 모드로 열면 사라지니, 가끔 JSON으로 백업해 두세요.
