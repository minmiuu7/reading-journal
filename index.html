GitHub 동기화 (기기 간 무료 동기화)

비공개 저장소 하나에 서재를 저장해 두면 폰·맥에서 같은 서재를 봅니다. 저장소·토큰은 무료이고, 토큰은 이 브라우저에만 저장되며 JSON 백업에는 들어가지 않아요.

  1. GitHub에서 비공개(Private) 저장소를 하나 만들어요. (예: reading-journal-data)
  2. Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access: Only select repositories에서 위 저장소만 선택
  4. Repository permissions → Contents: Read and write 하나만 켜고 생성
  5. 위 두 칸에 저장소(아이디/저장소이름)와 토큰을 넣고 연결 확인
