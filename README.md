# 📚 페이지로그 — 읽은 책 · 읽는 책

**페이지로그**는 무료 개인용 독서 기록 웹앱입니다.
`index.html` 파일 하나로 동작합니다. 빌드·서버·설치·회원가입 없이, 열면 바로 쓸 수 있고 데이터는 브라우저 안(localStorage)에 저장됩니다.
원하면 **GitHub 비공개 저장소 한 개로 폰·맥 서재를 무료로 자동 동기화**할 수 있습니다.

## 여는 방법

- **인터넷 주소로 쓰기(권장)**: https://minmiuu7.github.io/reading-journal/ — 폰·맥 어디서나 같은 주소
  - iPhone: Safari로 열고 **공유 → 홈 화면에 추가** 하면 홈 화면에 **`페이지로그`** 이름으로 앱처럼 추가됩니다.
- **Mac**: `index.html`을 더블클릭 (Safari/Chrome에서 열립니다)
- **iPhone(파일)**: 파일 앱이나 iCloud Drive에 올린 뒤 Safari로 열기

## 화면

- **서재(홈 탭 · 기본 첫 화면)**: 맨 위 **전체 검색창**, 상태 탭(`전체 / 읽는 중 / 완독 / 중단`, 권수 표시 · 얇은 가로선 위 **밑줄 탭**), 카테고리 칩, 정렬(`등록순 / 가나다순`), 표지 그리드(모바일 3열 / 데스크톱 5열)
  - 표지 아래에는 **마지막 기록 한 줄**과 **마지막 기록일**, 오른쪽 `이어서 기록` 버튼(기록이 없으면 `첫 기록`)이 함께 보입니다.
  - 상태 탭 구분선 아래 **13px 여백**을 두고, **카테고리 칩(왼쪽, 넘치면 가로 스크롤)** 과 **정렬 상자(오른쪽 고정)** 가 모바일·데스크톱 모두 **한 줄**에 놓입니다. 칩이 넘칠 때는 양끝에 작은 `‹` `›` 화살표가 나타나고(끝에서는 흐려짐), 손가락으로 옆으로 밀어 넘기는 것도 그대로 됩니다.
  - 칩은 **언제나 왼쪽 끝(`전체` 칩)부터 왼쪽에 붙여 차곡차곡** 쌓이고, 새 카테고리는 **오른쪽으로만** 늘어놓니다(`justify-content: flex-start`, 칩은 줄어들지 않음). `‹` 화살표와 `전체` 칩 사이는 **5px**이고, 칩 목록이 바뀌거나(카테고리 추가·삭제, 상태 탭 이동) 창 폭이 바뀌면 스크롤 위치도 **왼쪽 끝으로 되돌려** 왼쪽에 빈 여백이 생기지 않습니다. 스크롤이 0일 때는 왼쪽 끝을 흐리게 하는 마스크도 걸지 않습니다.
  - 표지는 **잘리지 않고 전체가 보입니다**(`object-fit: contain`). 표지 비율이 칸과 다르면 여백이 생기고 그 자리는 부드러운 종이색으로 채웁니다.
  - **완독한 책**은 표지 오른쪽 위 모서리에 **`완독` 책갈피 리본**(테마 강조색)이 붙습니다.
  - 별점을 매긴 책은 **표지 바로 아래에 금색 별 5개**(꽉 찬 별·반쪽 별·빈 별)로 점수가 보입니다. 별점이 없는 책은 이 줄을 비워 둡니다.
- **캘린더 탭**: 책을 **시작한 날**에 그 책의 표지가 채워지고, **문장이나 메모를 남긴 날**에는 점이 찍히는 월간 달력 (아래 참고)
- **책 상세**(표지를 누르면 열림): 카테고리·상태 배지, 제목·저자·출판사·시작일·완독일·마지막 기록, 상태 변경, **내 별점**(0.5점 단위) → 바로 아래 `읽는 이유` 카드 → **`후기` 카드**(같은 납작한 카드, 테마별 다른 색) → `하이라이트 모아보기`·`↓ .md 내려받기`·`정보 수정` 버튼 줄 → **`독서 노트`** 통합 카드(① **인용·쪽수·내 생각** 기록과 목록, 구분선 아래 ② **`생각 노트`** 마크다운 편집기)
- **하단 탭바**: `캘린더` · `홈` · `설정` — 가운데 **홈**이 서재이고, `설정`은 ⚙️ 설정 창을 바로 엽니다
- ⚙️ **설정 및 백업**: 폰트, 페이지 컬러 테마, 카테고리 추가·색상, 도서 검색 API 키, GitHub 동기화, JSON 백업 — 맨 아래에 저장 방식 안내가 있습니다(서재 화면에는 푸터 문구가 없습니다)

## 상태 탭

서재 위쪽 `전체 N · 읽는 중 N · 완독 N · 중단 N` 은 **밑줄 탭**입니다. 둥근 알약 바 대신 얇은 가로선 위에 네 탭을 나란히 두고, 고른 탭만 진한 글자색과 **테마 강조색의 둥근 밑줄**(높이 4px, `border-radius:99px` · 모바일 3.5px)로 표시합니다. 누르면 그 상태의 책만 남고 권수는 항상 함께 보입니다.

## 정렬

서재의 카테고리 칩 오른쪽 `등록순 / 가나다순` 버튼으로 바꿉니다. 고른 방식은 이 브라우저에 저장되어 다음에 열어도 유지됩니다.

- **등록순**: 최근에 담은 책이 앞 (기본)
- **가나다순**: 제목을 한국어 기준(`localeCompare('ko')`)으로 정렬

## 서재 전체 검색

서재 맨 위 검색창에 단어 하나를 넣으면 서재의 모든 책에서 **제목·저자**, **인용 문장**, **내 생각(메모)**, **후기**, **마크다운 독서 노트**를 한꺼번에 찾습니다.

- 결과마다 **책 제목 · 검색어가 들어간 문장(발췌, 검색어 강조) · 저장된 쪽수**(`42쪽`, `42~43쪽`)가 보입니다. 생각 노트에서 찾은 결과에는 쪽수 대신 `생각 노트`, 후기에서 찾은 결과에는 `후기`라고 적힙니다.
- 결과를 누르면 그 책의 상세창이 열리고 **해당 기록 카드로 바로 스크롤·초점**이 이동합니다(노트 결과는 노트 입력칸으로).
- 검색 중에는 상태 탭·카테고리 칩 대신 결과 목록이 보이고, 오른쪽 `✕`로 검색을 지우면 원래 서재로 돌아옵니다.

## 서재 카드 — 이어서 기록 / 첫 기록

책 제목 아래에 마지막으로 남긴 문장이나 메모가 **한 줄**로 보이고(길면 말줄임표), 그 아래 줄 왼쪽에 **마지막 기록일**, 오른쪽에 **`이어서 기록`** 버튼이 있습니다.

- `이어서 기록`을 누르면 그 책의 상세창이 열리면서 **새 기록 입력칸(인용문·쪽수·내 생각)이 바로 열리고 초점**이 들어갑니다.
- 아직 인용이나 메모가 없는 책에는 **`첫 기록`** 버튼만 보이고, 누르면 똑같이 입력칸이 열립니다.
- 카드는 키보드로도 열립니다(`Tab`으로 옮기고 `Enter`/`Space`).

## 인용 · 쪽수(선택) · 내 생각 기록

책 상세의 **인용 · 쪽수 · 내 생각** 카드에서 문장과 생각을 남깁니다. 입력 순서는 **인용문 → 쪽수(선택) → 내 생각**이고, 인용문만, 내 생각만, 둘 다 저장할 수 있습니다.

- **쪽수**: 숫자 칸 하나(`42`)와 `쪽`, 오른쪽 `범위 입력` 버튼. `범위 입력`을 누르면 끝 쪽 칸이 나타납니다.
  - 끝 쪽을 비우거나 시작 쪽과 같게 두면 `42쪽`, 끝 쪽이 더 크면 `42~43쪽`, 둘 다 비우면 쪽수를 표시하지 않습니다.
  - 끝 쪽이 시작 쪽보다 작으면 입력칸 아래에 **`끝 쪽은 시작 쪽과 같거나 커야 해요`**가 뜨고 저장되지 않습니다.
- 저장한 쪽수는 해당 **인용문 바로 아래에 작은 글씨**로 보이고, 한 책에 여러 기록이 있으면 각각 따로 저장됩니다.
- **수정**을 눌러 오타를 고치거나 쪽수를 넣어도 **기록의 날짜(처음 작성한 날)는 바뀌지 않습니다.**
- 기록은 책 데이터의 `entries` 배열(`{id, date, createdAt, updatedAt, quote, pageStart, pageEnd, thought}`)로 저장되어 **GitHub 동기화·JSON 백업·`.md` 내려받기**에 함께 들어갑니다.
- 기존 마크다운 독서 노트는 그대로 남아 있고, 상세 화면에서 계속 편집할 수 있습니다.

## 읽는 이유 · 후기 카드

책 상세의 `읽는 이유` 바로 아래에 **`후기`** 박스가 있습니다. 두 박스 모두 입력한 만큼만 높아지는 납작한 자동 확장 카드이고, 왼쪽 굵은 선 없이 얇은 테두리 한 줄만 쓸니다.

- **색 구분**: `읽는 이유`는 테마의 피치 톤, `후기`는 테마별 다른 틴트 — 기본(세이지 그린), 어스(틸), 스프링(스카이블루), 내추럴(올리브골드).
- **저장**: `book.review`에 자동 저장되고 저장할 때마다 `updatedAt`이 갱신됩니다. GitHub 동기화(`canonState`·payload)·JSON 백업·`.md` 내려받기·서재 전체 검색에 모두 포함됩니다(검색 결과에는 `후기`로 표시).

## 키보드 접근성 (책 상세창)

- 카드에서 `Enter`/`Space`로 상세창을 열면 **키보드 초점이 창 안으로** 들어갑니다.
- `Tab`과 `Shift+Tab`은 상세창 안의 버튼·입력칸들만 돌고 **창 밖으로 나가지 않습니다**(포커스 트랩).
- `Esc`로 닫으면 상세창을 열었던 **원래 카드(또는 버튼)로 초점이 돌아옵니다.**

## 캘린더

- 상단 `<` `2026년 11월` `>` 로 달을 옮기고, 오른쪽 `● N권`은 그 달에 시작한 책 수입니다.
- 요일은 **월요일 시작**(월 화 수 목 금 토 일)입니다.
- 책을 시작한 날짜 칸은 **플랫**합니다. 그라데이션 오버레이나 장식 없이 색면만 채웁니다.
  - 실제 표지 이미지(URL·업로드·붙여넣기)가 있으면 사진이 칸을 가득 채우고, 날짜 숫자만 작은 흰 배지로 읽히게 얹습니다.
  - 표지 이미지가 없으면 **카테고리 색**(지정한 색, 없으면 기본 단색 `#D8CEBA`) 배경 위에 **책 제목만** 올립니다.
- 같은 날 책이 2권 이상이면 오른쪽 아래에 `+N`이 붙고, 칸을 누르면 그 날 시작한 책 목록에서 골라 상세로 들어갑니다. 1권이면 바로 상세가 열립니다.
- 기준은 책의 **시작일**이며, 시작일·완독일은 `책 추가`(`상세 정보`)와 `정보 수정`의 날짜 칸에서 직접 고칠 수 있습니다. 저장하면 캘린더의 표지 위치와 상세 시트 날짜가 즉시 함께 바뀝니다.
- **기록한 날에는 점**이 찍힙니다. 인용이나 내 생각을 남긴 날짜 숫자 아래(칸 바닥)에 작은 점이 생기고, 같은 날 책을 시작하고 기록도 남겼다면 **표지와 점이 함께** 보입니다.
- **점이 있는 날을 누르면** 그날 남긴 기록이 모두 모인 시트가 열립니다: 기록마다 **책 제목 · 쪽수(`42~43쪽`) · 인용/메모 내용**이 보이고, 누르면 그 책 상세의 해당 기록으로 이동합니다. 그날 시작한 책도 시트 아래에 함께 보입니다.

## 캘린더에서 책 찾기

캘린더 탭 맨 위 검색창에 **제목이나 저자**를 넣으면 내 서재의 책이 바로 나옵니다.

- 결과마다 표지·제목·저자·상태와 **시작일 / 완독일**이 보입니다.
- 결과를 누르면 그 책의 **시작일 달로 캘린더가 이동**하고 **책 상세 시트**가 열립니다. 시트를 닫으면 이동한 달의 캘린더가 그대로 보입니다.
- 검색 중에는 달력 대신 결과 목록이 보이고, 검색어를 지우거나 `Esc`를 누르면 원래 달력으로 돌아옵니다.

## 책 추가

`+ 책 추가` → 제목을 검색하면 표지·저자·출판사와 함께 **카테고리까지 자동으로** 채워집니다. 검색 소스를 고르는 단계 없이 검색창 하나만 있습니다.

**카테고리** 입력칸과 추천 카테고리 칩은 제목·저자 바로 아래에 늘 보입니다. `정보 수정`에서도 `상세 정보`를 펼치지 않아도 카테고리가 그대로 보여 바로 바꿀 수 있습니다(추천 칩을 누르거나 직접 입력).

**검색 결과가 없을 때**는 `이 제목으로 바로 기록` 버튼이 나타납니다. 누르면 방금 검색한 제목이 채워지고 **첫 기록 입력칸(인용문·쪽수·내 생각)이 바로 열린 채 초점**이 들어가며, 표지·출판사·별점 등은 **`상세 정보` 접기/펼치기**에 접어 둔 채로 `서재에 추가`를 누르면 책과 첫 기록이 함께 저장됩니다. 검색이 안 되거나 결과가 마땅치 않아도 제목만으로 서재에 담고 바로 기록을 남길 수 있습니다.

카테고리는 결과의 제목·소개·출판사·API 카테고리를 보고 `마음·습관`, `마케팅·브랜딩`, `일·커리어`, `문학·언어·예술`, 그리고 서재에 이미 만든 카테고리 중 가장 알맞은 곳을 고릅니다(Google Books의 영문 카테고리도 한국어 카테고리로 옮겨 매칭). 마땅한 곳이 없으면 비워 두고, 직접 입력한 카테고리는 덮어쓰지 않습니다.

| 검색 소스 | 키 필요 | 비고 |
|---|---|---|
| 카카오 책 검색 | REST API 키 | 설정에 키가 있으면 항상 이것으로 먼저 검색합니다 |
| Google Books | 없음 | 키가 없거나 카카오 검색이 실패할 때. 무료 한도가 찼을 때(429)는 자동으로 Open Library로 넘어갑니다 |
| Open Library | 없음 | openlibrary.org, 키 없이 무료 |

키는 ⚙️ **설정 및 백업**에서 넣고, 이 브라우저에만 저장됩니다(developers.kakao.com → 앱 설정 > 일반 > 플랫폼 키). 검색이 안 되거나 다른 표지를 쓰고 싶으면 **직접 입력**하고, 표지 이미지는 URL을 붙여넣거나 파일로 올리면 됩니다(자동으로 줄여서 저장).

**표지 붙여넣기**: 인터넷 서점 같은 사이트에서 표지 이미지를 복사해 `책 추가`/`정보 수정` 창에서 `Cmd+V`(휴대폰은 입력칸을 길게 눌러 붙여넣기)만 하면 표지로 바로 들어갑니다. 이미지 파일이면 가로 480px으로 줄여 넣고, 이미지 주소(`https://...jpg`)를 붙여넣으면 URL 칸에 채워집니다.

## 별점 (0.5점 단위)

책 상세 시트의 상태 바 아래 `내 별점`, 그리고 `책 추가`/`정보 수정` 창에서 별점을 매깁니다. **0 ~ 5점, 0.5점 간격**입니다.

- 별 5개의 **왼쪽 절반**을 누르면 `2.5`처럼 반 점, **오른쪽 절반**을 누르면 `3`처럼 한 점이 바로 들어갑니다(터치·마우스 동일).
- 지금과 **같은 값을 한 번 더 누르면 `0`(별점 없음)** 으로 지워집니다.
- 고른 값은 별 옆에 `4.5`처럼 작게 표시되고, 서재 표지 아래에는 **금색 별 5개**(가뜩 찬 별·반쪽 별·빈 별)로 보입니다. 별점이 없는 책은 그 줄을 비워 두어 제목 줄이 나란히 정렬됩니다.
- 키보드로도 고를 수 있습니다: `←` `→` 로 0.5점씩, `Delete`/`Backspace` 로 지우기.
- 별점은 책 데이터의 `rating`(0~5, 0.5 단위) 필드로 `localStorage`에 저장되고 `updatedAt`도 함께 갱신되어 **GitHub 동기화·JSON 백업에 그대로 포함**됩니다. `.md` 내려받기에는 머리말 `rating:` 으로 들어갑니다.

| 항목 | 반영되는 곳 |
|---|---|
| 인덱스 (`#` 제목) | 미리보기의 제목 글자 |
| 일반 텍스트 | 미리보기 본문·목록 글자, 편집 입력창 기본 글자색 |

## 카테고리 관리·색상 (⚙️ 설정 및 백업)

카테고리를 직접 추가하고 카테고리마다 색과 순서를 정해 두면 서재·캘린더·상세가 그 색과 순서로 이어집니다. `settings.categoryColors`·`settings.customCategories`·`settings.categoryOrder`·`settings.hiddenCategories`에 저장되고 GitHub 동기화로 다른 기기에도 넘어갑니다.

- **추가하는 곳**: ⚙️ 설정 → **카테고리** → `+ 추가` 옆 입력칸에 이름(예: `에세이`, `가드닝`)을 넣고 **추가**를 누르면 바로 색상 시트가 열립니다. (책이 0권이어도 서재 카테고리 칩과 `책 추가`/`정보 수정`의 카테고리 추천 목록에 남습니다.)
- **삭제**: 기본 4개(`마음·습관`, `마케팅·브랜딩`, `일·커리어`, `문학·언어·예술`)를 포함해 **모든 카테고리 줄 오른쪽 `✕`** 로 삭제합니다. 확인 후 목록·추천 칩에서 빠지고, 그 카테고리를 쓰던 책은 **카테고리 없음**으로 바뀝니다(기본 카테고리는 `settings.hiddenCategories`에 기록되어 새로고침·동기화 후에도 숨김 유지, 같은 이름을 다시 추가하면 되살아납니다).
- **순서**: 각 줄 왼쪽 `↑` `↓` 로 카테고리 순서를 바꿉니다. 바뀐 순서는 `settings.categoryOrder`에 저장되어 **서재 카테고리 칩 줄과 `책 추가`/`정보 수정` 추천 목록**에 그대로 반영되고 GitHub 동기화로 다른 기기에도 넘어갑니다.
- **지정하는 곳**: 카테고리를 누르면 색상 시트가 열립니다.
- **기본 팔레트**: 빨간색 `#FF3B30` · 주황색 `#FF9500` · 노란색 `#FFCC00` · 초록색 `#34C759` · 파란색 `#007AFF` · 보라색 `#AF52DE` · 갈색 `#A2845E` · **기본(색 없음)**
- **사용자화…**: iOS 색상 시트처럼 **격자**(12색상 × 10단계) · **스펙트럼**(2D 색판, 드래그) · **슬라이더**(R/G/B 0~255 + 16진수)로 직접 정합니다.
- **반영되는 곳**: 카테고리 필터 칩(점·테두리·활성 색), 책 상세의 카테고리 배지, 표지 이미지가 없을 때의 자동 표지 색, 캘린더 칸 단색 배경

## GitHub 동기화 (기기 간 무료 동기화)

폰과 맥의 서재를 같은 상태로 맞춥니다. **비공개 저장소 1개 + 무료 Fine-grained 토큰**이면 되고, 서버가 필요 없습니다.

### 준비 (한 번만, 1~2분)

1. GitHub에서 **비공개(Private)** 저장소를 하나 만듭니다. (예: `reading-journal-data`)
2. https://github.com/settings/personal-access-tokens/new 열기 → **Fine-grained token** 생성
3. **Repository access** → `Only select repositories` → 위 저장소만 선택
4. **Repository permissions** → **Contents: Read and write** 하나만 켜기 (나머지는 그대로)
5. 앱의 ⚙️ 설정 → **GitHub 동기화**에 `아이디/저장소이름`과 토큰을 넣고 **연결 확인**

### 동작

- 저장 위치: 저장소의 `data/journal.json` 한 파일 (UTF-8 ↔ Base64, 한글 안전) — 책마다 `entries`(인용·쪽수·내 생각) 배열도 함께 오갑니다
- **자동 동기화 켜짐(기본)**: 앱을 열 때 Pull, 책 추가·수정·삭제·노트 저장 시 **5초 뒤** 자동 Push(연속 저장은 묶어서 한 번만)
- **요청 간격**: 자동 동기화는 앞선 시도에서 **30초**가 지나야 다시 하고, 폰으로 돌아올 때(화면 복귀)의 자동 Pull은 마지막 동기화 후 **60초**가 지났을 때만 합니다
- **속도 제한 보호**: GitHub이 `403 rate limit`(또는 `secondary rate limit`)을 돌려주면 `잠시 동기화 요청이 많아 GitHub이 속도 제한을 걸었어요. 몇 분 뒤에 다시 시도해 주세요.`라고 안내하고 자동 동기화를 **2분 이상** 멈춥니다(그동안 `지금 동기화`는 직접 누르면 시도). 권한이 모자란 일반 403은 그대로 토큰 권한 안내를 보여 줍니다
- **지금 동기화**: 수동으로 Pull → Merge → Push
- **연결 확인**: 실제 GitHub API로 저장소·`journal.json` 접근을 확인하고 결과를 알려 줍니다
- **동기화 해제**: 토큰·저장소 설정만 지웁니다. 이 기기의 책과 저장소에 올린 서재는 그대로 남습니다
- 상단 ⚙️ 옆 배지가 상태를 보여 줍니다: `동기화됨` / `동기화 중…` / `오류` (누르면 즉시 동기화)

### 안전하게 합치는 방식

- 책마다 `updatedAt`(마지막 수정 시각)이 있어, 두 기기에서 서로 다르게 고쳐도 **최신 것을 골라 합칩니다.**
- 삭제는 `deleted: {책id: 삭제시각}` 기록으로 남겨, 다른 기기의 예전 데이터가 삭제한 책을 되살리지 않습니다. (삭제 기록보다 새 수정이 있으면 되살아납니다)
- `409 Conflict`가 나면 최신 `sha`를 다시 받아 재병합한 뒤 한 번 재시도합니다.
- 1MB가 넘는 파일은 GitHub의 blob API로 읽어 옵니다.
- **토큰은 `localStorage`의 별도 키(`reading-journal.sync.v1`)에만 저장되며, JSON 내보내기 파일에는 절대 들어가지 않습니다.**
- 저장소는 비공개이고, 토큰 권한은 그 저장소의 Contents만이라 다른 저장소에는 접근하지 못합니다. 공용 기기에서는 **동기화 해제**로 토큰을 지우세요.

- **JSON 내보내기**: 서재 전체(책·인용/내 생각 기록·노트·상태·표지)를 파일 하나로 저장 — 토큰·설정은 포함되지 않습니다
- **JSON 가져오기**: 다른 기기에서 만든 JSON을 이 서재에 **합칩니다** (이미 있는 책은 건너뜀)

> GitHub 동기화를 켜지 않았다면 데이터는 이 브라우저에만 있습니다. 브라우저 데이터를 지우거나 시크릿 모드로 열면 사라지니, 가끔 JSON으로 백업해 두세요.

## GitHub Pages로 올리기 (무료)

1. github.com에서 새 저장소 만들기 (Public)
2. `index.html` 업로드 (Add file → Upload files)
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `/ (root)` → Save
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 주소로 열기
