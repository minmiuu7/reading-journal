# 📚 책 — 읽은 책 · 읽는 책

**무료 개인용 독서 기록 웹앱**입니다.
`index.html` 파일 하나로 동작합니다. 빌드·서버·설치·회원가입 없이, 열면 바로 쓸 수 있고 데이터는 브라우저 안(localStorage)에 저장됩니다.
원하면 **GitHub 비공개 저장소 한 개로 폰·맥 서재를 무료로 자동 동기화**할 수 있습니다.

## 여는 방법

- **인터넷 주소로 쓰기(권장)**: https://minmiuu7.github.io/reading-journal/ — 폰·맥 어디서나 같은 주소
  - iPhone: Safari로 열고 **공유 → 홈 화면에 추가** 하면 앱처럼 쓸 수 있습니다.
- **Mac**: `index.html`을 더블클릭 (Safari/Chrome에서 열립니다)
- **iPhone(파일)**: 파일 앱이나 iCloud Drive에 올린 뒤 Safari로 열기

## 화면

- **서재(책 탭)**: 상단 요약(`N권 · 조각 M장`), 상태 탭(`전체 / 읽는 중 / 완독 / 중단`), 분야 칩, 정렬(`등록순 / 가나다순`), 표지 그리드(모바일 3열 / 데스크톱 5열)
- **캘린더 탭**: 책을 **시작한 날**에 그 책의 표지가 채워지는 월간 달력 (아래 참고)
- **책 상세**(표지를 누르면 열림): 분야·상태 배지, 제목·저자·출판사·시작일·완독일·마지막 기록·조각 수, 상태 변경, `하이라이트 모아보기`, `읽는 이유` 카드, 마크다운 독서 노트
- **하단 탭바**: `캘린더` · `홈` · `책` (`홈`은 아직 준비 중 안내가 뜹니다)
- ⚙️ **설정 및 백업**: 폰트, 페이지 컬러 테마, 도서 검색 API 키, GitHub 동기화, JSON 백업

## 정렬

서재의 분야 칩 오른쪽 `등록순 / 가나다순` 버튼으로 바꿉니다. 고른 방식은 이 브라우저에 저장되어 다음에 열어도 유지됩니다.

- **등록순**: 최근에 담은 책이 앞 (기본)
- **가나다순**: 제목을 한국어 기준(`localeCompare('ko')`)으로 정렬

## 캘린더

- 상단 `<` `2026년 11월` `>` 로 달을 옮기고, 오른쪽 `● N권`은 그 달에 시작한 책 수입니다.
- 요일은 **월요일 시작**(월 화 수 목 금 토 일)입니다.
- 책을 시작한 날짜 칸에는 그 책의 표지가 칸을 가득 채우고, 어두운 반투명 그라데이션 위에 흰 날짜 숫자가 보입니다.
  - URL 표지, 붙여넣기/업로드한 표지(DataURL), 표지가 없을 때 자동으로 그려지는 표지 모두 지원합니다.
- 같은 날 책이 2권 이상이면 오른쪽 아래에 `+N`이 붙고, 칸을 누르면 그 날 시작한 책 목록에서 골라 상세로 들어갑니다. 1권이면 바로 상세가 열립니다.
- 기준은 책의 **시작일**이며, 시작일은 책 추가/정보 수정에서 넣을 수 있습니다.

## 책 추가

`+ 책 추가` → 제목을 검색하면 표지·저자·출판사가 자동으로 채워집니다.

| 검색 소스 | 키 필요 | 비고 |
|---|---|---|
| Google Books | 없음 | 기본. 무료 한도가 찼을 때(429)는 자동으로 Open Library로 넘어갑니다 |
| Open Library | 없음 | openlibrary.org, 키 없이 무료 |
| 알라딘 | TTBKey | 알라딘 Open API에서 무료 발급. JSONP 방식이라 서버 없이 브라우저에서 바로 호출됩니다 |
| 카카오 | REST API 키 | developers.kakao.com → 내 애플리케이션 → REST API 키 |

키는 ⚙️ **설정 및 백업**에서 넣고, 이 브라우저에만 저장됩니다. 검색이 안 되거나 다른 표지를 쓰고 싶으면 **직접 입력**하고, 표지 이미지는 URL을 붙여넣거나 파일로 올리면 됩니다(자동으로 줄여서 저장).

**표지 붙여넣기**: 알라딘 같은 사이트에서 표지 이미지를 복사해 `책 추가`/`정보 수정` 창에서 `Cmd+V`(휴대폰은 입력칸을 길게 눌러 붙여넣기)만 하면 표지로 바로 들어갑니다. 이미지 파일이면 가로 480px으로 줄여 넣고, 이미지 주소(`https://...jpg`)를 붙여넣으면 URL 칸에 채워집니다.

## GitHub 동기화 (기기 간 무료 동기화)

폰과 맥의 서재를 같은 상태로 맞춥니다. **비공개 저장소 1개 + 무료 Fine-grained 토큰**이면 되고, 서버가 필요 없습니다.

### 준비 (한 번만, 1~2분)

1. GitHub에서 **비공개(Private)** 저장소를 하나 만듭니다. (예: `reading-journal-data`)
2. https://github.com/settings/personal-access-tokens/new 열기 → **Fine-grained token** 생성
3. **Repository access** → `Only select repositories` → 위 저장소만 선택
4. **Repository permissions** → **Contents: Read and write** 하나만 켜기 (나머지는 그대로)
5. 앱의 ⚙️ 설정 → **GitHub 동기화**에 `아이디/저장소이름`과 토큰을 넣고 **연결 확인**

### 동작

- 저장 위치: 저장소의 `data/journal.json` 한 파일 (UTF-8 ↔ Base64, 한글 안전)
- **자동 동기화 켜짐(기본)**: 앱을 열 때 Pull, 책 추가·수정·삭제·노트 저장 시 약 1.5초 뒤 자동 Push
- **지금 동기화**: 수동으로 Pull → Merge → Push
- **연결 확인**: 실제 GitHub API로 저장소·`journal.json` 접근을 확인하고 결과를 알려 줍니다
- **동기화 해제**: 토큰·저장소 설정만 지웁니다. 이 기기의 책과 저장소에 올린 서재는 그대로 남습니다
- 상단 ⚙️ 옆 배지가 상태를 보여 줍니다: `동기화됨` / `동기화 중…` / `오류` (누르면 즉시 동기화)

### 안전하게 합치는 방식

- 책마다 `updatedAt`(마지막 수정 시각)이 있어, 두 기기에서 서로 다르게 고쳐도 **최신 것을 골라 합칩니다.**
- 삭제는 `deleted: {책id: 삭제시각}` 기록으로 남겨, 다른 기기의 예전 데이터가 삭제한 책을 되살리지 않습니다. (삭제 기록보다 새 수정이 있으면 되살아납니다)
- `409 Conflict`가 나면 최신 `sha`를 다시 받아 재병합한 뒤 한 번 재시도합니다.
- 1MB가 넘는 파일은 GitHub의 blob API로 읽어 옵니다.
- **토큰은 `localStorage`의 별도 키(`reading-journal.sync.v1`)에만 저장되며, JSON 내보내기 파일에는 절대 들어가지 않습니다.**
- 저장소는 비공개이고, 토큰 권한은 그 저장소의 Contents만이라 다른 저장소에는 접근하지 못합니다. 공용 기기에서는 **동기화 해제**로 토큰을 지우세요.

## 백업

⚙️ 설정 및 백업 →
- **JSON 내보내기**: 서재 전체(책·노트·상태·표지)를 파일 하나로 저장 — 토큰·설정은 포함되지 않습니다
- **JSON 가져오기**: 다른 기기에서 만든 JSON을 이 서재에 **합칩니다** (이미 있는 책은 건너뜀)

> GitHub 동기화를 켜지 않았다면 데이터는 이 브라우저에만 있습니다. 브라우저 데이터를 지우거나 시크릿 모드로 열면 사라지니, 가끔 JSON으로 백업해 두세요.
